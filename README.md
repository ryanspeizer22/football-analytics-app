# PitchSense — Football Analytics Summary App

AI-powered football match intelligence with a gaming-inspired dashboard.
Search a team or matchup — or click a legendary fixture — and get a
three-layer summary generated by Claude from live API-Football data.

| Layer | Tab | What you get |
|---|---|---|
| 1 | ⚡ The Shockwave | 2–3 sentence recap of the match |
| 2 | ⚔️ Tactical Breakdown | Per-team narrative, animated stat bars, key-stat chips |
| 3 | 🔥 MVP Battleground | Player trading cards with rarity tiers by rating |

A fourth **🔮 Elite Intel** tier (formations, pressing patterns, buildup
structure, turning points) is stubbed out as a future premium feature.

## Interface

- **Smart search** — type a team (`Arsenal`, `spurs`, `barca`) or a matchup
  (`Liverpool vs Man United`) for instant autocomplete. Matching runs against a
  local team registry, so typing never burns API quota. Press `/` to focus.
- **Trending & Iconic grid** — pre-seeded legendary fixtures (the 2022 World Cup
  final, Liverpool 7–0 United, City 4–0 Madrid) for zero-friction entry.
- **Team-reactive theming** — each match paints the page with its clubs' colors.
  Near-black kits are lightened and same-colored derbies fall back to a
  secondary color so the coding always stays readable.

## Stack

- **Backend:** FastAPI + Uvicorn
- **Data:** [API-Football](https://www.api-football.com/) (free tier)
- **AI:** Anthropic API (Claude) with structured outputs — the three layers
  come back as validated JSON in a single model call
- **Frontend:** Jinja2 template with a tabbed, dark-mode dashboard (no build step)

## Setup

```bash
git clone https://github.com/ryanspeizer22/football-analytics-app.git
cd football-analytics-app

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

cp .env.example .env   # then fill in your two API keys
```

You need two (free-tier) keys in `.env`:

- `FOOTBALL_API_KEY` — from [api-football.com](https://www.api-football.com/)
  (note: the free plan only covers seasons 2021–2023)
- `ANTHROPIC_API_KEY` — from [platform.claude.com](https://platform.claude.com/)

## Run

```bash
.venv/bin/uvicorn main:app --reload
```

Open <http://127.0.0.1:8000>, enter a fixture ID, and hit **Analyze**.

## API

| Route | Description |
|---|---|
| `GET /` | Dashboard UI |
| `GET /api/search?q=` | Team/matchup autocomplete (local, no API call) |
| `GET /api/trending` | Pre-seeded iconic fixtures for the homepage grid |
| `GET /api/fixtures?team1=&team2=` | Head-to-head or recent fixtures for a team |
| `GET /api/match/{fixture_id}/summary` | Three-layer AI match summary (JSON; `?refresh=true` to regenerate) |
| `GET /api/player/{player_id}/stats?season=YYYY` | Season stats + AI scouting note |
| `GET /api/premium/tactical/{fixture_id}` | Premium tactical tier (placeholder) |
| `GET /health` | Health check |
